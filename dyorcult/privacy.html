DYORCULT Privacy Policy

Last Updated: August 24, 2026

Overview

DYORCULT is a non-custodial mobile app for Solana. The developer never accesses private keys, seed phrases, or funds. Users approve and sign all transactions directly in their wallet app. The backend only sees public wallet addresses.

Information Collected

Wallet Information

The app connects via Mobile Wallet Adapter and receives only the public wallet address. Private keys, seed phrases, and wallet credentials are never requested, transmitted, or stored.

Transaction Signatures

The server may request a message signature from the wallet to verify ownership (for example, when minting an NFT). These signatures only prove control of an address and cannot move funds or execute transactions.

NFT Minting Data

When a user mints an NFT, the app uploads the chosen photo and its metadata (name, description) to the server, which stores them permanently on Arweave via Irys and records the resulting mint address in a Supabase database so the app can display the user's minted NFTs. The cost of storage and the Solana network fee are paid by the user in SKR, swapped to SOL as part of the same signed transaction.

Tipping Feature

Users can send SKR token tips directly to the creator's wallet address. Tips are blockchain transactions that users sign and send through their own wallet. The app facilitates the transaction but does not custody, control, or have access to the funds. All tips are staked automatically by the recipient.

Device Permissions

The app only requires:

  • Internet access: Required for blockchain transactions, NFT media uploads, and Solana network connectivity.
  • Photo library access: Required to select a photo to mint as an NFT.

Information Not Collected

No collection of names, email, phone, physical address, government ID, or other personally identifying information unless voluntarily provided (e.g., via support email). No analytics SDKs, crash reporting, or advertising trackers.

Third-Party Services

Jupiter

Token swap quotes and execution communicate directly with Jupiter's API from the device, sending public wallet address and swap parameters. Users approve and sign transactions themselves.

Helius (Solana RPC)

On-chain data is read through a server-side proxy that forwards allow-listed read-only requests to Helius, protecting API credentials from exposure.

Irys / Arweave

Photos and metadata for minted NFTs are uploaded to permanent Arweave storage via Irys, paid for by a wallet the developer funds and controls solely for this purpose. Uploaded content is public and permanent by the nature of Arweave storage.

Use of Information

Information is used only to:

  • Verify wallet ownership for user-initiated actions
  • Upload and permanently store NFT media and metadata on the user's behalf
  • Display on-chain balances, transaction previews, and minted NFTs
  • Facilitate SKR tips to the creator's wallet
  • Respond to direct support requests

No selling, renting, or sharing of information for advertising or marketing.

Security

Private keys and seed phrases never leave the user's device or wallet app. Server-side secrets are stored server-side only, never in the app. No transmission or storage method is 100% secure.

Children's Privacy

Not directed to users under 18. Users must be at least 18 years old (or age of majority in their jurisdiction). No knowing collection from those who don't meet this requirement.

User Choices

  • Disconnect wallet at any time
  • Stop using minting or tipping features at any time; no account required
  • All transactions are user-initiated and require explicit wallet approval

International Users

Available globally. Minimal data collection means most international data protection frameworks have limited application. Residents with specific data rights can contact the developer to address requests.

Policy Changes

Policy may be updated as the app evolves. Material changes will update the "Last updated" date. Continued use after changes constitutes acceptance.
